## 二、可用的真实素材

### 2.1 先厘清一个概念：APEC 的成员叫「经济体」不是「国家」

APEC 官方明确说明：使用 "economies"（经济体）一词来描述成员，是因为 APEC 合作进程**主要处理贸易与经济议题，成员以经济实体身份相互交往**。这个细节很适合做网页开头的科普小卡片。

### 2.3 APEC 的"含金量"数据（做数据可视化）

| 指标 | 数值 |
|---|---|
| 成员经济体 | **21 个** |
| 覆盖人口 | 约 **26 亿**，约占世界 **40%** |
| 经济总量 | 占世界 **超 60%**（GDP 之和超 19 万亿美元） |
| 贸易额 | 约占世界总量 **48%** |
| 关税变化 | 亚太地区平均关税从 **17% 降至 5%** |
| 机制定位 | 亚太地区层级最高、领域最广、影响力最大的经济合作机制 |
| 三大观察员 | 东盟（ASEAN）秘书处、太平洋经济合作理事会（PECC）、太平洋岛国论坛（PIF）秘书处 |

### 2.4 2026 年的三个关键词（衔接峰会主题）

- 主题：**建设亚太共同体，促进共同繁荣**
- 优先领域：**开放、创新、合作**
- 会标：21 根交织羽翼构成的鲲鹏 → 恰好可以做成"21 个经济体 = 21 根羽翼"的互动彩蛋

> 🔗 **绝佳的互动设计**：APEC 2026 会标的官方寓意就是"21 根羽翼，各具特色、相互依存"。把百科做成 **21 根羽翼的交互图**，点一根羽翼展开一个经济体，天然把"知识科普"和"2026 峰会主题"缝在一起——既是这一个方向，也直接命中主题契合 20%。

## 三、网页模块建议

| 模块 | 内容 | 对应得分点 |
|---|---|---|
| 开篇科普卡 | "为什么 APEC 成员叫经济体？" | 主题契合 |
| 21 羽翼互动图 | 每根羽翼 = 1 个经济体，悬停高亮、点击展开详情 | 交互（核心亮点） |
| 经济体检索页 | 按**名称 / 区域 / 加入年份**筛选，实时过滤 | 交互与完成度 |
| 加入时间轴 | 1989 → 1991 → 1993 → 1994 → 1998 五批次动画 | 交互 |
| 数据看板 | 用柱状图对比人口/经济体量/贸易占比 | 技术应用 |
| 对比模式 | 勾选 2—3 个经济体并排对比 | 交互（加分项） |

**技术提示**：词条内容是"数据联动检索"，建议把 21 个经济体的资料写成独立的 **JSON 数据文件**（如 `data/economies.json`），页面用 JS 动态渲染 + 筛选。这样"数据驱动"的架构更容易被看出技术能力——比硬编码 HTML 表格得分更高。
