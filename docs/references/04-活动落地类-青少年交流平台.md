# 04 · 活动落地类

> 对应官方文档「主题三：AI Coding 网页开发」选题方向四

## 一、官方原文

**选题方向**
> 活动落地类：青少年线上交流平台。

**参考示例**
> 《少年亚太对话》线上交流活动落地页——面向青少年论坛的报名与展示页面；

## 二、这个方向和前三个的关键区别

前三个方向是"**展示既有信息**"（峰会资讯、城市风貌、经济体百科），这一个方向是"**承载一个真实动作**"——用户在页面上要**完成报名**。

所以它的评分重心天然偏向：

- 「**交互与页面完成度 20%**」——表单校验、提交反馈、状态切换
- 「**技术应用 30%**」——表单数据处理 + 线上部署可访问

> 📌 官方文档里《少年亚太对话》只是**命名示例**，活动本身需要你自己设计。下面给一套可直接用的活动方案骨架。

## 三、可用的真实素材（作为活动的背景锚点）

### 3.1 活动背景（真实、可引用）

- APEC 2026 领导人非正式会议将于 **2026 年 11 月 18—19 日**在深圳举行，主题「**建设亚太共同体，促进共同繁荣**」，优先领域「**开放、创新、合作**」
- APEC 全年约 **300 场**活动，其中专业部长会覆盖**人力资源、妇女**等与青年发展直接相关的领域
- 深圳是继 2001 上海、2014 北京之后**第三座**主办 APEC 领导人非正式会议的中国城市
- 深圳市南山区本身就是教育强区：**「百校焕新」**行动自 2022 年起分三年对 **143 所**学校和幼儿园全面焕新，2025 年继续提升 80 多所校园
- 本次赛事所在的**南山区第二十八届教育科技节**，正是"青少年 × 科技"的真实落地场景

### 3.2 活动方案骨架（示例，可自行调整）

| 项 | 建议填写 |
|---|---|
| 活动名称 | 《少年亚太对话》——APEC 2026 青少年线上交流活动 |
| 主办定位 | 面向南山及亚太青少年的线上交流与展示平台 |
| 活动时间 | 2026 年 10 月 — 11 月（峰会前预热） |
| 参与对象 | 南山区 4—8 年级在读学生（与本次赛事参与对象一致） |
| 活动形式 | 线上图文/短视频投稿 + 线上直播对话 + 成果展示页 |
| 主题方向 | 开放·创新·合作 三个分论坛（与 APEC 优先领域一一对应） |
| 语言 | 中文为主，配英文摘要（体现"亚太"属性） |

**建议议程（做成一栏时间轴）**

1. **开幕**：活动介绍 + APEC 2026 主题解读
2. **分论坛一 · 开放**：我眼中的亚太——各国青少年生活一天
3. **分论坛二 · 创新**：AI 如何改变我的学习——作品展示
4. **分论坛三 · 合作**：跨校/跨城结对——共同完成一件作品
5. **成果发布**：优秀作品线上展览 + 电子证书颁发

### 3.3 报名表单字段建议（体现完成度）

| 字段 | 类型 | 校验要求 |
|---|---|---|
| 姓名 | 文本 | 必填，2—10 字 |
| 年级 | 下拉 | 必填，四至八年级 |
| 学校 | 文本 | 必填 |
| 联系方式 | 手机/邮箱 | 必填，格式校验 |
| 监护人联系 | 文本 | 必填（未成年人保护） |
| 参与分论坛 | 单选/多选 | 必填，开放 / 创新 / 合作 |
| 作品类型 | 单选 | 图文 / 短视频 / 网页 |
| **监护人同意** | 勾选 | **必勾选才能提交** |
| 自我介绍 | 多行文本 | 选填，字数上限 |

> ⚠️ 赛事文档「五、其它说明」明确要求：作品如需出现个人信息，**须征得监护人同意，妥善处理未成年人个人信息**。在表单里放进"监护人同意"勾选项，是既合规又容易被评委注意到的细节。

## 四、网页模块建议

| 模块 | 内容 | 对应得分点 |
|---|---|---|
| Hero | 活动主视觉 + 倒计时（距活动开始/距峰会 11.18） | 交互 |
| 活动介绍 | 背景 + 方案表 3.2 | 主题契合 |
| 议程时间轴 | 5 个环节，点击展开详情 | 交互 |
| **报名表单** | 3.3 全部字段 + 实时校验 + 提交成功态 | 交互（核心） |
| 分论坛切换 | 开放 / 创新 / 合作三个 Tab，各配一组内容卡片 | 交互 |
| 作品展示墙 | 网格瀑布流 + 分类筛选（图文/短视频/网页） | 交互 |
| 常见问题 | FAQ 折叠面板 | 完成度 |
| 页脚 | 主办单位占位、版权与隐私说明、友情链接 | 合规 |

**交互点子（建议重点做 2—3 个）**
1. **表单实时校验**：输入时即时给出红/绿提示，提交按钮在未通过校验时保持禁用态
2. **提交成功动效**：提交后弹出"报名成功"卡片 + 报名编号，而不是简单 alert
3. **分论坛 Tab 切换**：用 CSS 过渡动画，切换时内容淡入
4. **倒计时组件**：精确到秒，配合 APEC 2026 峰会日期（11 月 18 日）
5. **作品展示墙筛选**：不刷新页面即可过滤，可加简单搜索框

**技术提示**：这一方向最适合作品"看起来能用"——表单交互做扎实，比堆砌视觉效果更能拿分。若时间有限，优先保证：**表单校验 + 提交反馈 + 三个分论坛切换**这三件事完整可用。
