## 一、先澄清一件事：文档里的「参考示例」没有网址

官方《附件5：AI赛项项目规则》中，主题三给出的 4 条「参考示例」原文如下：

| 选题方向 | 文档中的参考示例 | 有网址吗 |
|---|---|---|
| 峰会资讯类 | 《APEC 2026 深圳峰会主题网站》——峰会日程、场地、议题的可视化介绍页 | ❌ 无 |
| 城市名片类 | 《鹏城文化数字名片》——深圳 / 南山地标、滨海生态、科创硅谷的多页面展示 | ❌ 无 |
| 知识科普类 | 《亚太经济体互动百科》——21 经济体文化、数据联动检索页 | ❌ 无 |
| 活动落地类 | 《少年亚太对话》线上交流活动落地页 | ❌ 无 |

**这 4 个是「命题示例名」，不是已经存在的作品，文档没有给出任何对应的网站链接。**
整份规则文档里**只有一个网址**：

- 参赛平台（Tcamp）：<https://tcamp.qq.com/spoc/cq_sh_zx_camp> — ✅ 200

也就是说，赛事**不提供官方范例网站**。作品要做成什么样，靠我们自己找参照。

## 三、怎么用这份清单

**别照抄，照抄会丢「创意与原创性 20%」。** 正确用法是分三层：

1. **事实层——只从权威站取**
   时间、主题、优先领域、会标寓意取 `gov.cn` / `mfa.gov.cn` / `apec.org`；南山数据取 `szns.gov.cn`。这一层**必须准**，直接决定「主题契合 20%」。

2. **形态层——参考官方专题站的骨架**
   `sz.gov.cn/en_szgov/news/infocus/APEC2026/` 和 `shenzhen.gov.cn/.../APEC/xwzx` 已经给出了"APEC 专题页该怎么组织"的答案（会议排期 / 新闻流 / 议题分类）。学它的**信息层级**，但视觉和交互要重新设计。

3. **作品层——去学生赛事作品池找手感**
   `huodong.ncet.edu.cn` 的往届优秀作品，可以看同龄人做到的完成度水位线在哪，避免自己定位过高或过低。

## 四、还需要注意

- 上面链接于 **2026-10-04** 实测可访问，政府网站路径（`content/post_xxxxx.html`）会随改版变化，用之前建议再点一次。
- 会议具体日程、场馆、议程**官方尚未全部公布**，页面里请写「待官方发布」，不要编造。
- 素材引用建议在页面 footer 或"资料说明"里标注来源，既是严谨性，也是原创性维度的加分点。
