# 《码上亚太》项目过程文档

> **赛项**：南山区第二十八届教育科技节 · AI 赛项 · **主题三 AI Coding 网页开发**
> **作品**：《码上亚太》Code the Pacific —— 面向 APEC 2026 深圳峰会的 AI 网页（单项目 · 四入口）
> **说明**：本文严格按官方点名的四个小标题分节，便于评委一眼对上评分点。另两项材料（**作品录屏演示视频**、**首页及核心页高清截图**）与**公网可访问网址**单独提交。

## 一、页面功能介绍

一个应用、一套外壳，四个入口从首页展厅自由进入，顶部入口切换器随时跳转（hash 路由，深链刷新不 404）。

- **E-01 峰会资讯**：会标「鲲鹏 · 21 根羽翼」三层解读、办会主题与三大优先领域（开放/创新/合作）、全年会议年历时间轴、议题矩阵（10 场部长会）、关于 APEC 与"为什么是深圳"、距 11 月 18 日开幕的**实时倒计时**。
- **E-02 鹏城文化数字名片（主推）**：招牌原创交互 **「八景一张图」**——手绘南山示意地图，点位点击 ↔ 八景卡片双向联动、支持上下景轮播与独立详情页；一海一河一城一湖、企业梯队**手写 SVG 柱状图**、科创雨林（龙头/新锐企业）、海洋南山、交通新地标、深港同城。
- **E-03 亚太经济体互动百科**：开篇"为什么叫经济体"科普、**21 根羽翼会标彩蛋**（点/悬停展开对应经济体）、APEC 含金量看板、按名称/英文名/批次**实时检索 + 区域筛选**、加入批次时间轴、**对比模式**（勾选 2–3 个并排比）。
- **E-04 少年亚太对话**：活动信息、议程时间轴、分论坛三 Tab 切换、FAQ 折叠面板、报名**诚实说明**（无后台→跳第三方表单）。

全站三档响应式、滚动淡入进场、页面切换淡入，交互稳定流畅。

## 二、开发思路

- **架构决策**：作品为**纯前端、无后台**——这是主动选择（静态托管更稳定、加载更快、且不收集任何用户信息，天然规避"未成年人信息需监护人同意"红线）。
- **数据与视图分离**：八景/南山/APEC/21 经济体/活动全部写进 `src/data/*.json`，组件只渲染。`src/data/` 就是"无后台项目里的数据库"，改文案不碰组件。
- **单项目四入口 + 同源不同貌**：三入口共享同一套设计系统与外壳，只换强调色与核心交互（E-02 海绿/八景地图、E-03 数据蓝/检索、E-01 鎏金/会标时间轴）。
- **技术栈**：Vite 8 + Vue 3.5（`<script setup>`）+ Vue Router 5（hash）+ Tailwind CSS 4（CSS-first `@theme`）+ 手写 SVG。**不引入 Pinia、不引入重型动画库**——"少一个依赖就少一个出错点"，直接服务于「交互稳定」。
- **设计系统**：`@theme` 定义山海配色 / 字体三栈 / 4·8 间距 / 圆角 / 阴影 / 动效时长；`--accent` 随入口切换，组件一律引用变量、不写死颜色。
- **推进节奏**：先出 30+ 个 HTML 风格原型做横向比选 → 每入口收敛 1 套定稿 → 翻译为 Vue 组件 → 内容期数据驱动填充 → 交互期做联动/轮播/彩蛋/对比/滚动淡入。
- **部署**：GitHub Actions 构建 `dist/` 发布到 GitHub Pages；`vite.config.js` 写死 `base: '/code-the-pacific/'` 防上线白屏；本地 `npm run build && npm run preview` 验证整条工具链。

## 三、AI 辅助编码使用说明

**用了哪些 AI 工具**：以对话式编码助手为主，承担需求梳理、技术选型、设计原型、组件骨架、数据规格化与交互实现；录屏/文档中同步标注所用工具（赛项推荐腾讯 CodeBuddy / 元宝等，按实际填写）。

**分几类任务用 AI**：
1. 生成组件骨架（AppHeader / InfoCard / SceneMap / DataPanel 等）；
2. 编写 Tailwind 类名与响应式布局；
3. 设计并生成**手写 SVG**（南山地图、21 羽翼、企业梯队柱状图）；
4. 生成 `src/data/*.json` 数据结构；
5. 调试构建报错与浏览器兼容。

**AI 生成后我改了什么（具体）**：
- AI 初版倒计时把变量提前使用、且无清理 → 改为 `onMounted` 起 `setInterval`、`onUnmounted` 清除，避免切页泄漏；
- AI 生成的八景卡片在手机端溢出 → 加 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4` 断点；
- 样式注释里 `--color-*/` 的 `*/` 提前闭合了 CSS 块注释导致报错 → 改写注释文本；
- 对比/百科里给"中国台北"配了国旗 emoji，违反"成员是经济体、不是国家" → 改为中性占位、文案严守规范。

**AI 帮不上、靠自己的部分**：
- 南山八景的地图点位坐标，是照着南山片区**手工标定**的示意位置；
- 配色取自会标"鲲鹏 + 山海"意象、**手工定色阶**；
- "无后台/报名走第三方/不臆造各经济体 GDP 与人口"等**诚实与合规边界**由人来把关；
- 所有数据均**核对官方来源**（APEC 官网、中国政府网、南山区政府等）后才写入。

## 四、南山特色元素设计思路

- **视觉母题「山海连城 · 绿美南山」**：一海（深圳湾、43.7 km 海岸线）、一河（大沙河 13.7 km）、一城（南头古城近 1700 年）、一湖（西丽湖 15.5 km），加一岛（内伶仃）、一山（阳台山）——抽成配色与图形符号，贯穿四入口共享地基。
- **南山八景（2026 年 9 月揭晓的最新素材）**：直接作为 E-02 的主导航结构，做成"八景一张图"原创交互（手绘 SVG + 点位联动 + 详情页）。
- **科创元素**：企业梯队、龙头（腾讯/中兴/大疆）与新锐（速腾/拓竹/xTool）数据，用手写柱状图呈现"中国硅谷"活力。
- **跨入口都有南山落点**：峰会=主办城区南山（前海/后海/深圳湾超总）；百科=前海深港合作区、西部港区、企业出海；活动=南山"百校焕新"143 所学校。
- **版权合规**：八景图标与母题均为**原创手绘 SVG**，不使用受版权保护的实景照片/品牌 Logo；企业仅以名称 + 公开报道数据引用并标注来源。
